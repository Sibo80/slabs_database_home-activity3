Question 1


a) Vertical application software: Software designed for a specific industry or business. It performs tasks for a particular type of organisation

Example: Hospital management software used to manage patients, appointments and medical records

Horizontal application software: Software designed for general use across different industries and businesses

Example: Microsoft Word, which can be used by students, teachers and office workers

b)Real-time processing: Data is processed immediately when it is entered or received. The results are available almost immediately

Example: When you withdraw money from an ATM, your bank balance is updated immediately

Batch processing: Data is collected and stored before being processed together at a scheduled time

Example: A company processing employees' salaries at the end of the month


Question 2

a)Redundant data means storing the same information more than once in a database. It is harmful because it wastes storage space and can cause data inconsistencies when information is updated in one place but not another
b)Primary Key: A column that uniquely identifies each record in a table. It cannot contain duplicate or NULL values

Foreign Key: A column that connects one table to another by referring to the Primary Key in another table

Example for database:
The courses table has course_id as its Primary Key
The enrollments table has course_id as its Foreign Key
The Foreign Key connects each enrolment to an existing course
